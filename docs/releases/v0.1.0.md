# v0.1.0

Released 2026-07-07.

The initial implementation of `draft-hardt-oauth-aauth-protocol-09`.

## Highlights

- Agent identity and tokens.
- HTTP message signatures.
- The three-party token exchange.
- The agent `Transport`, which answers challenges and retries.
- Permission and audit endpoints.
- Call chaining, clarification chat, and interaction chaining.

## Upgrading

v0.2.0 implements a later draft and is not wire-compatible with v0.1. See
[Migrating from v0.1](../guides/migrating-from-v0.1.md).
